JSON FIELDS

test_type
Must be one of: "NORMAL", "DC", "BOUNDARY", "ROBUSTNESS". Never omit this field.

initial_condition
Describes ONLY the software/system state before execution — never inputs, outputs, or expected behaviour.

- Primary Surfaces: Aileron, Elevator, Rudder — generate a separate test case for each.

DECISION COVERAGE (DC)

BOUNDARY TESTS

ROBUSTNESS TESTS
